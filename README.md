A geeky Valentine's Day website for two CS software engineers. Host it on GitHub Pages in a few steps.

## Deploy to GitHub Pages (github.io)

1. **Create a new repo** on GitHub (e.g. `valentines-cs` or `username.github.io` for a user site).

2. **Push this folder** to the repo:
   ```bash
   cd /Users/harsha/valentines-cs-website
   git init
   git add .
   git commit -m "Valentine's Day site"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```

3. **Turn on GitHub Pages**
   - Repo → **Settings** → **Pages**
   - Under "Build and deployment", set **Source** to **Deploy from a branch**
   - Branch: **main**, folder: **/ (root)**
   - Save

4. **View your site** at:
   - `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/` (project repo), or  
   - `https://YOUR_USERNAME.github.io/` (if the repo is exactly `username.github.io`)

That’s it. Happy Valentine’s Day.
